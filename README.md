A simple and functional Hotel Management System built using Python (IDLE). This project helps manage hotel operations like room booking, customer check-in/check-out, and billing.

📌 Features
🧾 Customer check-in & check-out
🛏️ Room booking & availability
🗃️ Basic customer records management
📊 View Customer Records & Booking Details
🗄️ Persistent data storage via MySQL database

🛠️ Tech Stack
Python 
MySQL (via mysql-connector-python)
IDLE (for development)
